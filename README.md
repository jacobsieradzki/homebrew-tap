# homebrew-tap

A Homebrew tap for the tools in [jacobsieradzki](https://github.com/jacobsieradzki).

```bash
brew install jacobsieradzki/tap/pyscythe
```

| Formula | What it is |
| --- | --- |
| [`pyscythe`](https://github.com/jacobsieradzki/pyscythe) | Dead code, import cycles, duplication, complexity, and architecture boundaries for Python codebases |

The formulas pour the binaries attached to each GitHub Release rather than
building from source, and they are written by the release workflow of the
project they belong to. Issues belong in that project.
